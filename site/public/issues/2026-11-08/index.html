05 NovGitDevelopment

GitHub rebuilt Git storage so 5,000 agents can push to one repository

Project Rubicon stores packs in Azure Blob Storage and agrees only on reference updates. A test sent 7,200 pushes a second to one repo.

Follows GitHub Enterprise now includes Copilot, and Fusion picks the model · Vol. 1 · No. 4

GitHub announced the design at Universe and now explains how it works. Git objects are immutable and named by their contents, so two writers can store them at the same time; only the reference update needs agreement. Virtual replicas are disposable compute whose local disk is a cache. A replicated log service called Ref-CAS commits each reference change as a compare-and-swap, and compaction nodes merge packs in the background, away from the replicas that serve traffic. Today the busiest repositories take at most dozens of writes a second; GitHub set a target of at least two orders of magnitude more. OpenAI went its own way: Pando, a Git-compatible backend built for the scale of development that Codex makes possible. Next on GitHub's list: agents that work without a clone.

06 NovARC RaidersDevelopmentBonus

Embark's CEO: “We could just frankly add PvE”

Almost half the rounds in the PvE test ran on the PvE server. Embark now has to serve both camps without watering down the tension.

Follows 30 million PvE rounds later, ARC Raiders needs time to think · Vol. 1 · No. 3

Patrick Söderlund told The Game Business that adding PvE is “not a difficult thing to do”. The fear was the core loop: in a PvPvE game, other players add tension, and removing one substantial component means “fiddling with the core emotional loop”. “We’ve now since tried it and realised that it’s fine,” he said. Executive producer Aleksander Grøndal said the team is still going through the data. Some players who asked for PvE changed their minds, because it lacked some of the game's values; others absolutely loved it. “Now it’s for us to figure out how we can cater to the specific needs of the players,” Söderlund said, but not at the expense of “the integrity of the experience itself”.
