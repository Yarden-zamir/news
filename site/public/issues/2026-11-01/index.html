30 OctSecurityDevelopment

The stolen certificate keys were the number 4

Cloudflare says eMudhra's eight broken keys were tiny numbers, starting with 4. A forged certificate appeared less than an hour after the news went public.

Follows Eight stolen certificate keys, and a week of patches · Vol. 1 · No. 3

Anyone can recover such keys from the public certificates, so this is no ordinary breach of a certificate authority. In a week, Cloudflare logged about 22,000 handshakes with the weak keys; about 160 carried certificates for other organizations' domains, but none looked like interception. Probes on 50 million challenge pages show modern browsers mostly patched, while bots and old browsers lag, and 30–40% of Android WebView clients still accept the chain. eMudhra is leaving the public CA business. JetBrains told users to update its IDEs, the Toolbox App and Gateway, and Python shipped five expedited security releases. Cloudflare's advice fits in one word: patch.

Fork changes

  1. 26 OctPin messages

    “With pins turned on in Settings > General > Behavior, a pin button marks a message, and thread details and a sidebar footer button list the pins with a link back to each message.”

  2. 27 OctGuest links over the Cloudflare tunnel

    “Fork machines without T3 Connect can share a thread with a guest through their Cloudflare tunnel host, and the portal Guests view sets up the Cloudflare Access rules for it.”

  3. 27 OctPortal stays within the Cloudflare free plan

    “The machine map portal writes far fewer Durable Object rows, so it no longer goes offline after reaching the daily free-plan limit.”

  4. 28 OctApp context menu

    “An optional setting draws right-click menus with the app's own themed menu, with icons, group names, submenus and typeahead, on web and desktop.”

  5. 29 Octkitshn publish tools for agents

    “Agents can publish pages, files and folder sites to kitshn with the new kitshn_publish, kitshn_address and kitshn_agent_key tools.”

  6. 30 OctWaiting shelf

    “Threads that show Waiting now sit in their own shelf under Working, on web, desktop and mobile.”

  7. 30 OctSafer diagnostics

    “Machine diagnostics send program names and redacted errors, not command lines that can hold tokens.”

  8. 31 Octkitshn replaces the machine map portal

    “kitshn is now the only path for machine identity, access, settings and links to other machines, and T3 reconnects when its kitshn provider child stops answering.”

  9. 01 Novkitshn provider protocol 2Bonus

    “T3 talks to kitshn over provider protocol 2: kitshn checks access, runs machine commands and names the host.”

Upstream changes

  1. 26 OctFaster thread loading

    “Opening a thread loads 85% less data, and a cold connect skips older settled threads, which cuts the shell JSON by 93%.”

  2. 27 OctGoals stop the running turn

    “A new goal sent during a turn stops that turn and runs first, Clear works while the agent works, and goals no longer echo back as a reply.”

  3. 28 OctSmaller MCP tool context

    “All T3 MCP tools now send compact schemas, which cuts the tool context of every thread by 23%, and CI fails when that context grows.”

  4. 29 OctLinked environments

    “Agents can link to another machine, @-mention it, and delegate tasks that run there, with links managed in Connections as a Labs beta.”

  5. 30 OctFallback model

    “When the default provider is out of usage, a new thread can use a fallback model you choose.”

  6. 31 OctStop always completes

    “Stop now always finishes, and an agent that ignores it gets a Force stop choice in the thread.”

  7. 31 OctDesktop back, forward and swipe

    “The desktop sidebar gets back and forward buttons, and a two-finger trackpad swipe navigates like a browser.”

  8. 01 NovSide chats

    “Open a side chat beside the main thread that starts with the thread's context.”

  9. 01 NovOne-time scheduled tasks

    “Schedule a task to run once at a specific date and time.”
